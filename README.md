# OnoySat - Лендинг

Современный адаптивный лендинг для компании OnoySat, специализирующейся на построении отделов продаж.

## Особенности

- 🎨 Современный дизайн с градиентами и эффектами
- 📱 Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- ⚡ Быстрая загрузка и оптимизированная производительность
- 🎯 Интерактивные элементы с плавными анимациями
- ♿ Доступность (accessibility) для всех пользователей

## Структура проекта

```
onoysat/
├── index.html          # Основная HTML страница
├── styles.css          # CSS стили с адаптивностью
├── README.md           # Документация
└── assets/             # Изображения и иконки
    ├── *.png           # Фоновые изображения
    └── *.svg           # Иконки и логотипы
```

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные стили с Flexbox и Grid
- **Google Fonts** - шрифты Gilroy и Raleway
- **CSS Animations** - плавные переходы и эффекты

## Адаптивность

Лендинг оптимизирован для всех устройств:

- **Мобильные** (320px - 767px) - одноколоночная верстка
- **Планшеты** (768px - 1023px) - двухколоночная сетка
- **Десктоп** (1024px+) - многоколоночная сетка
- **Большие экраны** (1440px+) - увеличенные размеры элементов

## Секции

1. **Header** - фиксированная навигация с логотипом
2. **Hero** - главный экран с призывом к действию
3. **Helping** - услуги компании
4. **Services** - подробное описание услуг
5. **Industries** - отрасли работы
6. **Cases** - кейсы и результаты
7. **Process** - процесс работы
8. **Price** - варианты стоимости
9. **Contact** - форма обратной связи

## Запуск проекта

1. Скачайте все файлы проекта
2. Убедитесь, что все изображения находятся в правильных папках
3. Откройте `index.html` в браузере

Или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000` в браузере.

## Особенности дизайна

### Цветовая схема
- Основной цвет: #006eff (синий)
- Фон: #000000 (черный)
- Текст: #fdfeff (белый)
- Акценты: градиенты синего

### Типографика
- **Gilroy** - для заголовков (жирный)
- **Raleway** - для основного текста (обычный, средний, полужирный)

### Эффекты
- Backdrop blur для стеклянных эффектов
- Градиенты для кнопок и акцентов
- Плавные анимации при наведении
- Тени для глубины

## Производительность

- Оптимизированные изображения
- Минимальное количество HTTP запросов
- Эффективные CSS анимации
- Быстрая загрузка шрифтов
